Uma (outra) introdução ao Manim

01/09/2026 — ManimMatemáticaAnimaçõesREASTEM

O que é Manim

Manim é uma biblioteca Python, feita para animações programáticas com foco em conteúdos matemáticos, essa biblioteca possui todas a ferramentas que precisamos para gerar gráficos, textos Latex e figuras geométricas, e ainda animar a posição, cor, tamanho e muitas outras coisas.

O que são animações programáticas

Animações programáticas são uma forma de criarmos animações usando programação, ou seja, nosso código é uma sequência de eventos que devem acontecer em uma dada animação.

Por que usar animações programáticas?

Imagine que você quer animar 100 retângulos para demonstrar a Soma de Riemann (aproximando a área sob a curva $y = \sin(x)$). Em software tradicional você precisaria calcular manualmente a altura de cada um dos 100 retângulos com base na função e redimensioná-los individualmente toda vez que quisesse testar um intervalo diferente. No Manim você escreve uma função que calcula a altura do retângulo $i$ como $f(x_i)$. Se quiser mudar de 10 para 1000 retângulos ou trocar a função para $y = x^2 \cos(x)$, é só alterar uma variável no código.

A primeira parte da animação Manim sempre segue a seguinte estrutura:

from manim import *

class Cena(Scene):
    def construct(self):

A primeira linha é um import, isso sinaliza para o Python que vamos usar uma biblioteca que já possui funcionalidades prontas, ou seja, toda vez que criamos um quadrado, escrevemos um texto LaTeX ou usamos um método de animação, essas funcionalidades veem todas dessa biblioteca.

Seria perfeitamente possível acessar esse código para descobrir todos os objetos e animações que o Manim nos fornece, porem, olhar para o código-fonte diretamente para encontrar funcionalidades específicas pode ser (e acredite em mim, realmente vai ser) uma tarefa tediosa e trabalhosa, por isso, sempre que estivermos em dúvida sobre alguma funcionalidade ou quisermos descobrir o que mais há na ferramenta nós podemos olhar a documentação.

Na documentação são só temos acesso a todas as funcionalidades da ferramenta, mas também temos acesso a guia de instalação e a uma galeria de exemplos.

As próximas duas linhas são definições de uma class e uma função usando def, existe um porquê dessas linhas existirem ali, porem para entendermos porque essas linhas estão ali precisamos mergulhar mais a fundo no funcionamento da ferramenta, e isso não seria muito produtivo. Algo que podemos fazer é usar o método da caixa preta, existe um porquê daquelas linhas, porem, vamos assumir que o Manim funciona assim e que essas linhas são necessárias sem nos preocuparmos no que essas linhas serão usadas e, porque elas existem.

Essas linhas definem uma cena, normalmente podemos alterar o nome da cena:

Vamos linha a linha para entender o que está acontecendo. Duas primeiras linhas definem objeto Manim:

circulo = Circle(color=BLUE)
quadrado = Square(color=RED)

Nesse caso estamos criando duas variáveis, uma chamada circulo e outra chamada quadrado, nessa variáveis estamos guardando objetos Manim que são criados usando as funções Circle() e Square() que como o nome sugere, são usados para criar círculos e quadrados respectivamente.

Dentro dessas funções estamos passando um atributo, nesse caso o atributo color, o círculo recebe a cor BLUE e o quadrado a cor RED. Já existe uma série de cores predefinidas dentro do Manim, na documentação podemos encontrar uma tabela com todas as cores disponíveis.

Toda criação de um objeto Manim segue esse padrão, vamos criar uma variável para armazenar o objeto, vamos usar uma função para criar o objeto e vamos passar atributos específicos para customizar os objetos.

As próximas quatro linhas é onde definimos a animação de fato:

self.play(Create(circulo))
self.play(Transform(circulo, quadrado))
self.wait()
self.play(FadeOut(circulo))

Todo método de animação é passado em um self.play(), novamente, isso tem um porquê, porem não vamos nos preocupar com isso agora, vamos assumir que isso precisa ser feito e seguir em frente. A primeira animação que usamos é a Create() perceba que criar um objeto Manim, ou seja, definir uma variável para armazenar um objeto Manim não significa que esse objeto está em cena, para colocar algo em cena precisamos especificar que algo deve ser mostrado.

Vamos analisar mais de perto, nas primeiras linhas definimos um quadrado e um círculo, porem, se observamos no começo da animação não temos os dois em cena, o primeiro a aparece é o círculo, o círculo só aparece quando definimos uma forma para que ele possa aparecer, nesse caso usamos o método Create() para indicar que o círculo deve ser criado dentro da cena.

O método Create() possui uma forma característica de anima objetos, e existem muitas outras formas de se colocar objetos em cena, como, por exemplo, FadeIn(), Write(), GrowFromCenter() ...

Logo em seguida usamos o método Transform(A,B) esse método sempre recebe ao menos dois atributos, que nesse caso, são dois objetos Manim, e ele faz o que o nome sugere, ele vai transformas o objeto A no objeto B, por isso que logo após o círculo ser criado na tela, ele é transformado em um quadrado.

Mais a frente, o método self.wait() é inserido, esse método adiciona uma pausa na animação, por padrão essa pausa é de um segundo, porem podemos especificar a pausa sem segundo dentro dos parênteses com, por exemplo: self.wait(2) para esperar 2 segundos ou self.wait(20) para esperar 20 segundos ou ainda self.wait(0.5) para esperar meio segundo.

Por último, usamos o método FadeOut() para remover a figura da tela, porem, se está prestando atenção talvez tenha percebido algo estranho, na tela temos o quadrado e não o circulo porque escrevemos FadeOut(circulo) e não FadeOut(quadrado) ?

A reposta é simples, quando usamos o método self.play(Transform(circulo, quadrado)) nós não substituirmos o círculo pelo quadrado, nós transformamos o círculo em um quadrado. Por isso, para tirar o quadrado da tela, precisamos usar FadeOut(circulo).

Se isso for um comportamento confuso (e acredite, normalmente é e gera muitos problemas e dor de cabeça), podemos usar o self.play(ReplacementTransform(circulo, quadrado)), dessa forma teremos a mesma animação, porem o quadrado tomara o lugar do círculo, e quando quisermos removê-lo de cena podemos usar o FadeOut(quadrado).

O fim da animação temos uma última parte:

title = Tex(r"Isso e um texto \LaTeX")
basel = MathTex(r"\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}")

VGroup(title, basel).arrange(DOWN)

self.play(
    Write(title),
    FadeIn(basel, shift=DOWN),
)

self.wait()

Essa parte segue o mesmo padrão que estávamos usando anteriormente, as duas primeiras linhas definem dois objetos Manim:

title = Tex(r"Isso e um texto \LaTeX")
basel = MathTex(r"\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}")

Nesse caso usamos os métodos Tex() e MathTex(). O método Tex() é usado para escrever texto, e o método MathTex() é usado para escrever formulas. Como argumento dessas funções precisamos passar uma string com um texto LaTeX.

Uma string nada mais é que um nome alternativo para texto, nesse caso, uma string sempre é escrita entre aspas "", mas especificamente para o Python e especialmente para strings com comando LaTeX precisamos colocar um r na frente (novamente, isso tem um porquê, mas não vamos nos preocupar com isso agora).

O primeiro objeto definimos um texto comum, porem usamos o comando \LaTeX, que basicamente coloca a logo do LaTeX ajustada.

O segundo objeto é a série infinita de basel uma série famosa resolvida por Euler em 1735.

$$\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}$$

Logo abaixo disso temos algo novo:

VGroup(title, basel).arrange(DOWN)

VGroup() é uma função extremamente útil dentro do Manim, talvez uma das mais uteis, tudo que ela faz é agrupar objetos, porem existe uma série de funcionalidades associadas a esses grupos, uma delas é o arrange().

Até agora fizemos a criação de dois objetos, title e basel, ambos são textos em LaTeX, porem por padrão o Manim cria todos os objeto no centro da tela, nesse caso, não seria interessante deixar dois textos sobrepostos (certamente não seria muito fácil ler eles), por isso precisamos arrumar os textos de forma que eles não fiquem sobrepostos.

Uma das maneiras de se fazer isso é usando a função arrange(), essa função recebe um atributo de direção, por padrão Manim possui uma série de vetores pré-configurados, segue alguns exemplos:

ORIGIN: Vector3D = np.array((0.0, 0.0, 0.0))
"""The center of the coordinate system."""  

UP: Vector3D = np.array((0.0, 1.0, 0.0))
"""One unit step in the positive Y direction."""  

DOWN: Vector3D = np.array((0.0, -1.0, 0.0))
"""One unit step in the negative Y direction."""  

RIGHT: Vector3D = np.array((1.0, 0.0, 0.0))
"""One unit step in the positive X direction."""  

LEFT: Vector3D = np.array((-1.0, 0.0, 0.0))
"""One unit step in the negative X direction."""  

IN: Vector3D = np.array((0.0, 0.0, -1.0))
"""One unit step in the negative Z direction."""  

OUT: Vector3D = np.array((0.0, 0.0, 1.0))
"""One unit step in the positive Z direction."""

Nesse caso estamos passando para a função arrange() o atributo DOWN, dessa forma, todos os elementos do nosso VGroup() serão alinhados um abaixo do outro.

Perceba também que os elementos estarão dispostos na ordem em que aparecem dentro do VGroup().

Poderíamos passar qualquer outra direção dentro do arrange() como UP, LEFT ou RIGHT:

VGroup(title, basel).arrange(UP)

Ou ainda criar um vetor qualquer usando o np.array():

vetor = np.array((2.0, 1.0, 0.0))

VGroup(title, basel).arrange(vetor)

Ou ainda poderíamos fazer uma combinação linear entre os vetores padrão do Manim:

VGroup(title, basel).arrange(2*RIGHT + UP)
#Essa combinação linear tem o mesmo efeito do vetor feito no exemplo acima

Por último na nossa animação temos:

self.play(
    Write(title),
    FadeIn(basel, shift=DOWN),
)

self.wait()

Essa seção apresenta poucas coisas novas, porem tem alguns detalhes interessantes.

Primeiro, o método self.play() agora possui dois atributos, um Write(title) e FadeIn(basel, shift=DOWN). Quando passamos mais de uma animação dentro do self.play() teremos que ambas as animações irão começar ao mesmo tempo, ou seja, elas irão acontecer em paralelo.

Essa é uma funcionalidade que precisa ser usadas com cautela dentro do Manim, uma vez que, ter coisas de mais acontecendo ao mesmo tempo, na tela pode ser distrativo.

Por último, a outra funcionalidade nova está na animação do basel, FadeIn(basel, shift=DOWN), aqui usamos o método FadeIn() para criar nossa fórmula na tela, porem usamos um atributo extra chamado shift, esse atributo indica a direção da animação, nesse caso ao invés de simplesmente aparecer na tela, a fórmula irá aparecer na tela enquanto faz um leve movimento de cima para baixo.

A última linha da animação é novamente um self.wait(), que irá esperar 1 segundo antes de acabar a animação.

Antes de falarmos sobre como mover figuras dentro do Manim precisamos investigar com mais detalhes o sistema de coordenadas do Manim, para isso, vamos usar um objeto muito útil, o NumberPlane(), vamos usar o seguinte código:

Função shift()

Animando movimento

Mas e se quisermos animar o objeto saindo de um ponto A para um ponto B?

Nesse caso temos algumas formas diferentes de fazer isso, vamos ver quais são elas. Grande parte dessas formas usam algo chamado animate, essa funcionalidade faz com que qualquer método de um objeto possa ser animado. Mas o que isso quer fizer?

Vamos pegar um exemplo:

from manim import *

class NumberPlaneExample(Scene):
    def construct(self):
        square = Square()
        square.set_color(BLUE)

        self.play(Write(square))

        self.wait()

Perceba que no código acima nós alteramos a cor do quadrado usando algo diferente, nesse caso o square.set_color(BLUE), isso tem o mesmo efeito de colocarmos o atributo color=blue na criação do objeto, a diferença é que em square.set_color(BLUE) nós estamos usando a função set_color() do objeto Square() para mudar a cor dele.

Todas essas funções podem ser usadas junto do animate para criar animações, vamos ver algumas que mudam a posição do objeto:

A primeira que vamos ver é a função shift() que nós já usamos antes, já vimos que a função shift() faz o movimento de um objeto seguindo um vetor, vamos implementar o código de exemplo que apresentamos naquela seção, mas agora mostrando o movimento do quadrado:

from manim import *

class NumberPlaneExample(Scene):
    def construct(self):
        number_plane = NumberPlane(
            background_line_style={
                "stroke_color": TEAL,
                "stroke_width": 4,
                "stroke_opacity": 0.1,
            }
        )
        self.add(number_plane)

        square = Square(color=RED)

        self.play(Write(square))

        self.wait()

        self.play(square.animate.shift(RIGHT * 2 + UP * 2))

        self.wait()

        self.wait()

Alinhando objetos com arrange(), next_to() e to_edge()

Vamos agora ver como podemos alinhar objetos. Por alinhamento vamos entender a posição de objetos relativos a outra coisa, seja a outro(s) objeto(s) ou seja, em relação às bordas da tela.

Função arrange()

Um método de alinhamento que já vimos é o método arrange() esse método é acessado dentro de grupos de objetos feitos usando VGroup(), vamos fazer um exemplo prático para entender seu funcionamento:

from manim import *

class Equations(Scene):
    def construct(self):

Função get_center()

A função get_center() nos retorna o centro de um objeto, o que pode ser particularmente útil quando precisamos mudar a posição de outro objeto para ser o centro de um segundo objeto, vamos ver um exemplo de aplicação:

Projeto 3 - Animações inteligentes

Nosso projeto para mostrar o cálculo da área de um quadrado parece bom, porem o que acontece se quisermos mudar o valor de $n$?

Nesse caso podemos alterar todas as linhas que contem o LaTeX que contem de algumas forma o valor de $n$, e essa é uma solução perfeitamente valida, mas isso pode acabar se tornando um problema rapidamente se nossa animação, por exemplo, conter diversas linhas para o desenvolvimento de uma conta.

Então como podemos resolver esse problema?

Nesse caso podemos usar uma variável para armazenar o valor de $n$ e usar uma função para calcular o valor da área. Vamos ver um exemplo simples:

n = 2

def area(lado):
    return lado ** 2

Até agora estamos usando variáveis do Python para armazenar objetos Manim, agora estamos usando uma variável n para armazenar um valor, nesse caso 2.

Na linha abaixo definimos uma função chamada area() essa função recebe um valor lado e retorna o lado elevado ao quadrado.

Mas como podemos usar isso na nossa animação?

Para usar essa estrutura na nossa animação podemos fazer da seguinte forma:

n = 2

def area(lado):

Logo abaixo fizemos uma alteração nas definições dos objetos MathTex():

valor_n = MathTex(r"n=",str(n),font_size=80)
conta1 = MathTex(r"A=",str(n),r"^2",font_size=80)

Perceba que tudo que fizemos foi alterar o texto de entrada para o LaTeX, porem, estamos fazendo uso da variável n e da função area() que definimos anteriormente, vamos ver o que esta acontecendo de fato nessas linhas, vamos tomar de exemplo a primeira linha:

valor_n = MathTex(r"n=",str(n),font_size=80)

Aqui podemos ver que definimos uma variável chamada valor_n, essa variável armazena o objeto Manim MathTex(), como vimos anteriormente, o objeto MathTex() precisa de uma string (ou um texto) para definir o que será escrito, nesse caso estamos passando duas strings, a primeira é r"n=" e a segunda fazemos uso da função str() para transformar n, que atualmente é um número, em uma string, nesse caso, o objeto MathTex() irá juntar as duas strings em uma, como definimos n=2 vamos ter que a string final para esse objeto MathTex() será: r"n=2" que é justamente o que queremos.

Os outros dois objetos MathTex() seguem o mesmo principio:

conta1 = MathTex(r"A=",str(n),r"^2",font_size=80)
conta2 = MathTex(r"A=",str(area(n)),font_size=80)

Nesse caso temos que conta1 terá o LaTeX correspondente a: r"A=2^2" e conta2 terá o LaTeX correspondente a: r"A=4^2".

Tente alterar o valor de n para 5, por exemplo, e renderize a animação para ver o resultado. Tente colocar outros valores arbitrários e veja o que acontece.

Por que isso é relevante?

O grande ponto de se usar uma linguagem de programação para se criar animações é poder usar toda a lógica de programação e ferramentas dessas linguagens para criar animações que sejam inteligentes, ou seja, animações que fazem alterações seguindo regras específicas sem que o animador (ou nesse caso, o professor) se preocupe em checar todos os objetos da sua animação.

Nesse caso fizemos o uso de uma variável e uma função do Python para criar uma animação extremamente fácil de ser adaptada para valores diferentes de $n$.

Vamos mudar o valor de n no código para 8 por exemplo:

Valores que se alteram de forma dinâmica e atualizando objetos

Essa é uma das maiores funcionalidades do Manim e talvez uma das mais interessantes e mais versáteis, porem, é certamente a mais complicada de se entender;

Exemplo 1

Vamos ver um primeiro exemplo de como aplicar esse conceito:

from manim import *

class ExemploValueTracker(Scene):
    def construct(self):
        linha_numerica = NumberLine()
        seta = Vector(DOWN)
        rotulo = MathTex("x")

        seta.next_to(linha_numerica.n2p(0),UP)
        rotulo.next_to(seta,UP)

        tracker = ValueTracker(0)

        def update_pointer(objeto):
            posicao = linha_numerica.n2p(tracker.get_value())
            objeto.next_to(posicao, UP)
            rotulo.next_to(objeto, UP)

        seta.add_updater(update_pointer)

        self.add(linha_numerica, seta, rotulo)        

        self.play(tracker.animate.set_value(5))
        self.wait(0.5)

        self.play(tracker.animate.set_value(3))
        self.play(tracker.animate.increment_value(-2))
        self.wait(0.5)

        self.play(tracker.animate.set_value(-5))
        self.wait(0.5)

        self.play(tracker.animate.set_value(0))
        self.wait(0.5)

        rotulo.next_to(seta,UP)

Nessa seção não temos muita coisa nova, temos 3 objetos sendo definidos, NumberLine(), Vector(DOWN) e MathTex("x"), muito embora 2 deles ainda não foram utilizados eles são bem intuitivos, NumberLine() faz uma reta numérica simples e Vector(DOWN) faz a representação de um vetor na direção inserida como parâmetro.

Logo abaixo fazemos uso de algo novo seta.next_to(linha_numerica.n2p(0),UP) o método n2p() é um método do NumberLine() que retorna as coordenadas de um ponto da reta, convertendo um número para um ponto (por isso n2p $\rightarrow$ number to point), nesse caso estamos posicionando a seta logo acima de um ponto específico (no caso do ponto $0$) e movemos o rotulo para cima da seta.

Abaixo temos algumas coisas novas:

tracker = ValueTracker(0)

def update_pointer(objeto):
    posicao = linha_numerica.n2p(tracker.get_value())
    objeto.next_to(posicao, UP)
    rotulo.next_to(objeto, UP)

seta.add_updater(update_pointer)
self.add(linha_numerica, seta, rotulo)        

self.play(tracker.animate.set_value(5))
self.wait(0.5)

Primeiro criamos um novo objeto Manim, o ValueTracker(), esse objeto nada mais é que uma forma de armazenar valores, a diferença desse objeto para algo como tracker=0 é que com o ValueTracker() temos diversas funcionalidades do Manim que são interessantes, vamos ver algumas mais a frente.

Além do ValueTracker() nos definimos uma função chamada update_pointer, essa função descreve quais alterações nosso objeto precisa seguir, nesse caso nossa função faz 3 coisas diferentes:

1) Primeiro nos criamos uma variável chamada posicao que recebe o valor linha_numerica.n2p(tracker.get_value()) a função n2p nos já analisamos antes, porem agora usamos a função get_value() no objeto tracker, ela é bem intuitiva, tudo que ela faz é retornar o valor que está armazenado atualmente no tracker. 2) Depois disso configuramos nosso objeto para ficar próximo da posição indicada deslocado para cima. 3) Por último fazemos o mesmo com o rótulo, mas ele deve ficar acima do objeto também deslocado para cima.

Mas quem é esse objeto?

Essa função recebe um objeto genérico e descreve um padrão de organização para o objeto e para outros objetos seguindo uma regra específica, nesse caso, toda vez que o valor do tracker mudar esse objeto será posicionado acima de um ponto correspondente ao tracker na NumberLine, e da mesma forma o rotulo será ajustado de acordo.

Por que fazer tudo isso se eu posso simplesmente mover a seta com um shift() ou com um move_to()?

Existe um motivo extremamente interessante do porquê fazer isso. Vamos continuar a analisar nosso código:

seta.add_updater(update_pointer)
self.add(linha_numerica, seta, rotulo)        

self.play(tracker.animate.set_value(5))
self.wait(0.5)

Na primeira linha indicamos para o objeto seta através do método add_updater() que o padrão de organização definido na função update_pointer, que nos criamos anteriormente, deve ser adicionado a ele.

Na linha abaixo inserimos todos os nossos objetos em cena com o self.add(), porem a animação que fazemos é a alteração do valor do tracker.

Esse é o porquê de fazemos tudo isso, agora, sempre que quisermos mover a seta a única coisa que precisamos fazer é animar a mudança de valor do tracker!

Perceba que o resto das animações são apenas alterações no valor do tracker:

self.play(tracker.animate.set_value(3))
self.play(tracker.animate.increment_value(-2))
self.wait(0.5)

self.play(tracker.animate.set_value(-5))
self.wait(0.5)

self.play(tracker.animate.set_value(0))
self.wait(0.5)

Isso facilita imensamente a logística da nossa animação, agora não precisamos nos preocupar com a seta e com o rótulo de forma individual, seus comportamentos dentro da animação agora estão fixos com o valor do tracker.

Esses tipos de comportamentos de animações Manim são chamados updaters.

Vamos fazer uma adição a esse exemplo, vamos adicionar um texto LaTeX com um x= com o valor do tracker:

from manim import *

class ExemploValueTracker(Scene):
    def construct(self):
        linha_numerica = NumberLine()
        seta = Vector(DOWN)
        rotulo = MathTex("x")

        seta.next_to(linha_numerica.n2p(0),UP)
        rotulo.next_to(seta,UP)

        tracker = ValueTracker(0)

        def update_pointer(objeto):
            posicao = linha_numerica.n2p(tracker.get_value())
            objeto.next_to(posicao, UP)
            rotulo.next_to(objeto, UP)

        seta.add_updater(update_pointer)

        texto = Tex(r"x=0.0")
        texto.shift(2*UP)

        def update_texto(objeto:Tex):
            valor = tracker.get_value()
            novo_objeto = Tex(f"x = {valor:.1f}").move_to(2 * UP)
            objeto.become(novo_objeto)

        texto.add_updater(update_texto)

        self.add(linha_numerica, seta, rotulo,texto)        

        self.play(tracker.animate.set_value(5))
        self.wait(0.5)

        self.play(tracker.animate.set_value(3))
        self.play(tracker.animate.increment_value(-2))
        self.wait(0.5)

        self.play(tracker.animate.set_value(-5))
        self.wait(0.5)

        self.play(tracker.animate.set_value(0))
        self.wait(0.5)

Perceba que quase tudo permanece igual, porem fizemos a adição da seguinte parte:

texto = Tex(r"x=0.0")
texto.shift(2*UP)

def update_texto(objeto):
    valor = tracker.get_value()
    novo_objeto = Tex(f"x = {valor:.1f}").move_to(2 * UP)
    objeto.become(novo_objeto)

texto.add_updater(update_texto)

self.add(linha_numerica, seta, rotulo,texto)

Criamos um objeto Tex() e posicionamos ele mais acima, até esse ponto nada de novo, porem logo a baixo criamos uma função para mudar o comportamento de um objeto, nesse caso estamos armazenando o valor do nosso tracker usando a função get_value().

Logo abaixo estamos criando um novo objeto Tex() esse objeto é exatamente igual ao nosso objeto original, porem o texto é igual a f"x = {valor:.1f}" esse é um tipo de string python onde podemos inserir valores usando {} nesse caso estamos inserindo o valor da variável valor, o :.1f indica que queremos com apenas 1 casa decimal de precisão (caso contrario teríamos um número desnecessariamente grande de casas na tela).

Por último estamos dizendo que o objeto precisa ser substituindo pelo novo_objeto usando o método become().

Adicionamos esse comportamento ao texto usando o método add_updater() e adicionamos o texto a cena dentro do método add().

Quando renderizarmos a animação teremos a indicação do valor de x na tela. Perceba que para isso não precisamos alterar mais nada na parte onde fazemos as animações de fato, tudo nessa animação é dependente do valor do tracker e os elementos se organizam e se alteram automaticamente quando o tracker é alterado.

Esse tipo de comportamento é o que deixa as animações Manim extremamente versáteis e inteligentes. Se quiser ver mais sobre esses tipos de animação segue algumas recomendações de exemplos na documentação do Manim:

  • ValueTracker
  • add_updater

Exemplo 2

Vamos tentar aplicar o conceito de updaters em uma animação simples com um gráfico. Vamos desenhar uma curva na tela com um ponto, e variar a posição desse ponto sobre a curva:

from manim import *

class Grafico(Scene):
    def construct(self):
        plano_catesiano = Axes(
            x_range=[-2, 2, 1],
            y_range=[-0.5, 4, 1],
            x_length=10,
            axis_config={"color": WHITE, "include_numbers": True},
        )

        legenda_plano_cartesiano = plano_catesiano.get_axis_labels()

        def func(x):
            return x**2

        curva = plano_catesiano.plot(func, color=BLUE)

        x = ValueTracker(0)

        ponto = Dot(
            point=plano_catesiano.c2p(x.get_value(), func(x.get_value()))
        )

        def update_ponto(objeto):
            novo_ponto = Dot(
                point=plano_catesiano.c2p(x.get_value(), func(x.get_value()))
            )
            objeto.become(novo_ponto)

        ponto.add_updater(update_ponto)

        self.add(plano_catesiano, legenda_plano_cartesiano, curva, ponto)
        self.wait(0.5)

        self.play(x.animate.set_value(2))
        self.wait(0.5)

        self.play(x.animate.set_value(-2))
        self.wait(0.5)

        self.play(x.animate.set_value(0))
        self.wait(0.5)

O começo do nosso código não possui nada muito novo, apenas replicamos o mesmo gráfico que fizemos anteriormente.

Depois disso criamos um Dot() com um atributo point que pode parecer estranho em um primeiro momento: plano_catesiano.c2p(x.get_value(), func(x.get_value())). O método c2p() está associado ao objeto Axes(), precisamos usar ele pois existe uma diferença entre as coordenadas do plano_cartesiano com as coordenadas da cena dentro do Manim, podemos observar essa diferença quando criamos um objeto Axes() com um NumberPlane():

Embora ambos os pontos utilizem as coordenadas $(2,2)$, eles estão em sistemas de referência diferentes. O ponto vermelho está posicionado no sistema de coordenadas globais do Manim (coincidindo com o NumberPlane), enquanto o ponto verde está nas coordenadas do próprio gráfico (Axes). Para posicionar um elemento corretamente no gráfico, usamos o método .c2p() (coords to point), que converte as coordenadas do plano cartesiano na posição exata da tela do Manim.

Nesse caso estamos definindo as coordenadas do nosso ponto (Dot) para as coordenadas (x.get_value(), func(x.get_value()) se analisarmos rapidamente o que isso faz podemos perceber que estamos colocando ponto nas coordenadas $(x,f(x))$ o que é justamente o que precisamos.

Logo abaixo podemos ver a função que vamos adicionar posteriormente como updater:

def update_ponto(objeto):
    novo_ponto = Dot(
        point=plano_catesiano.c2p(x.get_value(), func(x.get_value()))
    )
    objeto.become(novo_ponto)

ponto.add_updater(update_ponto)

Tudo que a função faz é a atualizar as coordenadas do ponto para o valor de x que é nosso ValueTracker e substituir o objeto pelo novo ponto usando o método become().

Por fim tudo que temos que fazer é mudar o valor do ValueTracker para termos nossa animação.

Agora que já sabemos todas as funcionalidades que precisamos vamos tentar implementar nosso projeto inicial.

from manim import *

class Projeto4(Scene):
    def construct(self):
        plano_catesiano = Axes(
            x_range=[-2, 2, 1],
            y_range=[-0.5, 4, 1],
            x_length=8,
            axis_config={"color": WHITE, "include_numbers": True},
        ).shift(LEFT*2)

        legenda_plano_cartesiano = plano_catesiano.get_axis_labels()

        def func(x):
            return x**2

        curva = plano_catesiano.plot(func, color=BLUE)

        x = ValueTracker(0)

        ponto = Dot(point=plano_catesiano.c2p(x.get_value(),func(x.get_value())))

        def update_ponto(objeto):
            novo_ponto =
                Dot(point=plano_catesiano.c2p(x.get_value(),func(x.get_value()))
                )
            objeto.become(novo_ponto)

        self.add(plano_catesiano, legenda_plano_cartesiano, curva, ponto)
        self.wait(0.5)

        valor_f_latex = MathTex(r"f(x)=",str(func(x.get_value())))
